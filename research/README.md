# Research

One file per report. Next to it, a `-what-this-changes.md` note in your own words.

**A report without a "what this changes" note doesn't count.** If a report changed no
decision, it was the wrong prompt — say so in the note, that's a useful result.

## Convention

```
R1-learning-evidence.md
R1-what-this-changes.md
```

## Run order

Then R2, R3. R4–R7, R9 are build-support and can wait until September.

Run each in a fresh conversation. Do not run them through the loop — these prompts
*define* the loop, so the loop can't be what runs them.
