# Recursion v3 consequential primary-source register

This is the canonical precision register for consequential external facts in the active v3
synthesis. Repository-local requirements and recommendations are not converted into external
facts. Every row records an immutable revision/content version when one was available; otherwise
it records the exact retrieval date and a fail-closed revalidation trigger. The Sol lead opened
each source listed here on 2026-09-03. Worker or model agreement is not evidence.

The `Supports` column is deliberately narrow. The `Does not establish` column retains decisive
counterevidence and applicability limits. If a required row expires, dependent claims become
`stale/unverified`, not silently current.

## Fail-closed use rule

A consequential factual claim may cite a row only when its wording fits both `Supports` and the
recorded applicability. An immutable URL does not eliminate applicability review. A mutable row
must be re-opened on its trigger; if this cannot be done, the dependent fact is marked
`unverified/stale`. Local experiments must additionally pin the actual dependency, host,
filesystem, endpoint, model, account class, SDK/CLI, policy and workload versions they use.

This register does not prove a v3 runtime, a provider entitlement, a cache saving, a scientific
claim, terminal containment, successful deletion, performance improvement or architecture
superiority.
