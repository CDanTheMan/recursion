## Refined contracts and actual evidence

One private-IPC authority owns selected generation/revision, publisher boot/serial, durable reader pins, drain intent and generation retirement state. A stable precreated byte-range lock admits one cooperating authority. A fresh boot invalidates the publisher permit, clears drain intent and preserves pins. Same-boot revocation increments the next permit serial; unique staging directories prevent old and new permits from sharing a candidate pathname. A writer stages completely and pauses before requesting publication. These are cooperating actors; an untrusted raw filesystem writer could still mutate files.

New pins bind the current generation/revision, exact directory/hash, fixture instance, owner and actor nonce. Existing pins retain old-generation rights after selection changes or authority restart. The controller checks a pin before launching a reader and waits that exact child before successful completion/death release. The authority itself validates the token and trusts the caller's release reason. Production principal authentication and OS access control are not established. An administrative cancel of a committed-but-never-launched orphan pin does not claim process death.

Publication checks actual staged files under the unchanged current permit. Both corrupt snapshot bytes and an absent required event refuse without changing selection; restoring the exact bytes allows publication. Persisting state before replying makes lost replies recoverable: staging-only loss leaves the old canonical state, while committed loss preserves the new pin or selection. Reclamation persists g1 retirement before bounded file deletion, and a restart resumes partial cleanup. A pin on g2 does not block g1 deletion.

The fixture uses two generations and payloads A, é, B, with event cursors 1/2/3 and UTF-8 byte cursors 1/3/4. Sixteen named schedules × two policies × two cursor units × two repetitions yield **128 cases, 400 owned helpers, 764 observed authority commits, 56 completed reads and 80 owned process terminations** per accepted execution. Twenty-four publications overlap a reader lifetime; eight g1 reclamations overlap a live g2 reader. The `two_pins` schedule holds two durable pins simultaneously but launches its second reader after the first exits; it is not a simultaneous-two-reader measurement.

The independent auditor imports neither authority nor producer. It reconstructs expected artifact bytes, request guards and state transitions from the retained JSONL journals and content-addressed snapshots. It binds grants to actor files/PIDs, staged blobs to committed blobs, read observations to fixed bytes, and released rights to prior owned waits. It checks physical deletion against durable retirement and pin state, stable lock identity and final files. The audit is an executable finite trace specification, not an exhaustive formal model. Synthetic adversarial journal/blob mutations test the validator; they are not additional observed integrations.

Experiment code contains no network/provider operations, but no OS or Python audit sandbox is claimed. The five-child cap is checked before spawn, command waits are bounded to ten seconds, owned kill/wait to five, and the whole experiment to 600 seconds. The 64 MiB artifact limit is checked at completion rather than continuously enforced. Outer timeout cannot prove descendant cleanup and must produce an incomplete checkpoint; no successful result may conceal it.

The lock test establishes same-range exclusion and bounded reacquisition after actual process kill/wait on this host. An offset-one lock-only control remains concurrent and is deliberately ineffective for offset-zero exclusion. It does not establish arbitrary filesystem sharing, mapped-write exclusion, cross-host leasing or exact UCRT-to-Win32 mapping. Bootstrap races, authority boot-write cuts, corrupt durable envelopes, permission failures, arbitrary reparse mutations, hostile callers and more than two generations are not tested. `acquisition_race` submits a stale selection/revision to an atomic authority operation; it is not an instrumented split-operation race. No power failure, reboot, live provider, installation or deployed service trial occurred. Timings are control records, not a performance ranking.
