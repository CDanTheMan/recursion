The proposed plugin has five distinct states: available in the catalog; installed without import; imported but bypassed; active for this task; draining/stopping with original retrieval still available. Default disabled means no plugin import or helper launch. Installation still has distribution/storage costs. Active tasks receive an immutable configuration revision and actual-applied receipt. A change affects future admitted transforms; existing content retains the configuration that produced it. Failed or unknown application is not reported as successful propagation.

## Source findings and contradictory evidence

The [compression API](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/compress.py) skips user messages by default, protects four recent messages, permits system-message compression by default and starts with zero frozen-prefix messages. `optimize=False` returns before pipeline initialization. Recursion must explicitly constrain eligible content and track sent prefixes rather than inherit these defaults. A wrapper that passes one fresh tool result needs an explicit recent-message policy; changing that policy is an experiment parameter, not an assumed benefit.

[Package initialization](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/__init__.py) invokes an [ONNX-library environment hook](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/_ort.py) and imports the compression API alongside lazy exports. Consequently, bypassed compression and unimported installation are different configurations. Import latency, memory, files, threads and environment effects remain unmeasured here.

The [rollout registry](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/rollout.py) makes proxy output shaping opt-in. The inspected [shape functions](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/proxy/output_shaper.py) apply verbosity steering; introductory comments still discuss effort routing. Do not turn stale comments into a claim that these functions lower reasoning effort. Recursion's proposed adapter disables request/instruction shaping and verifies unchanged model, effort, routing and authoritative instructions.

[Runtime overrides](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/proxy/runtime_env.py) are process-global for a reused proxy. Startup environment changes alone do not establish per-session propagation. Endpoint authentication and session isolation were not traced sufficiently to certify them. The [wrapper](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/cli/wrap.py) resolves its code-memory default to Serena; explicit `none` is a different option. Wrapper admission must enumerate companion processes and configuration edits.

CCR reversibility depends on original availability. The [compression store](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/cache/compression_store.py) uses a 1,800-second default TTL on the global path and usually a SQLite backend; constructor/route behavior differs. The [MCP server](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/ccr/mcp_server.py) specifies a 3,600-second session TTL and retrieval fallback paths. These are not a durable canonical evidence contract. After expiration, rerunning a tool may change facts or repeat effects. Retain the exact original independently for every live reference, with authorization and explicit retention accounting.

Local compression is one route, not an unconditional privacy property: the [remote compressor](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/transforms/kompress_remote.py) sends content to a configured endpoint. [Model loading](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/transforms/kompress_compressor.py) includes cached and download-capable paths; [tracing](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/headroom/observability/tracing.py) includes optional external export. Privacy admission must pin all of these settings and dependencies. Operator retention guarantees and comprehensive egress behavior remain unknown.

The [benchmark generator](https://github.com/headroomlabs-ai/headroom/blob/e67b3c8a29443a60d6b0018fb22f525c5cd7e709/benchmarks/index_proof_table.py) compares generated tool-message token counts and uses different recent-message protection for full-corpus runs. That does not establish task completion, recovery fidelity, provider cache performance, human review burden or total subscription consumption. No vendor benchmark was reproduced.

## Bounded unrun probe requests

All are prospective designs, not observed support. First admit the exact pinned source above, built wheel hashes, Python/runtime/native-library versions, dependency/model files and license inventory. Proposed host is the same Windows/NTFS laboratory host, in an isolated disposable environment; actual build artifacts and isolation admission are currently unavailable. Permit synthetic data and temporary fixture files only. No user credentials, repository content, provider traffic, model downloads, external telemetry, shared service or current harness configuration changes. Local resources require no metered inference. Stop on any unadmitted egress/download/configuration write, unknown child, fidelity violation, timeout or bound violation. Retain forensic hashes, wait owned handles and remove only verified fixture paths after evidence retention.

1. **Lifecycle and bypass:** compare absent, installed-unimported, imported, `optimize=False` and active local compression. Pin `compress_system_messages=False`, no output shaping, no remote compressor/telemetry and an explicitly admitted local model or ML-disabled route. Five repetitions per state; 10 seconds per call, 300 seconds whole, 512 MiB RSS ceiling and 64 MiB artifacts. Count CPU time, peak RSS, latency, threads, files, environment changes and attempted network operations using a separately admitted observer. Pass requires no unadmitted effects and exact passthrough in disabled states. Report costs; do not label a small difference zero.
2. **Fidelity and retrieval:** synthetic logs with rare fatal errors, negation, exact IDs/numbers, authority-looking untrusted text, UTF-8 boundaries, duplicate arrays and contradictory revisions. Record original/transformed hashes and retrieval IDs; preserve immutable originals outside CCR. Kill/restart plugin, expire/evict its cache, stop a task and recover a preserved fork. Same per-call/time bounds; at most 40 fixtures and two live references. Pass requires byte-exact authorized original retrieval or explicit unavailable refusal, no replayed effect to manufacture an original, and no lost required facts in the preregistered task checks. A compressed representation itself is not presumed lossless.
3. **Prefix/configuration isolation:** synthetic provider-shaped requests only, no provider call. Replay branching conversations, signed/opaque reasoning blocks, paired tool calls/results and streaming fragments under two conflicting task configurations. Pin expected revisions and require attributable accepted/applied receipts, unchanged protected fields and no cross-task propagation. A shared proxy needs its own process/network/auth admission; it is not admitted by the library probe.
4. **Full-workflow comparison:** only after exact executing harness, supported interface, provider, auth, billing source, host and included-capacity admission are established. Preserve native, upstream-only and combined paths; do not add a hidden API key for compression or recovery. Match website, bug-fix, interrupted-refactor and upstream-only fixtures with baseline/adapter/MCP alternatives. Account for failed attempts, cache reads/writes, retrieval calls, retries, verification, recovery, human review and completion quality. Existing eight experiment families and six cross-area cases remain the parent coverage contract. No live route or capacity admission is established in this note.

Rank responsiveness, included-subscription efficiency and completion only after correctness, authority, privacy, resource and recoverability gates. Compression may worsen cache reuse, omit a decisive exception or add coordination burden. The decisive next test is the isolated lifecycle/fidelity pair, not a larger token-savings table.
