# Generation authority source findings

These are primary-source observations and implementation inferences. File hashes, retrieval times, repository identities and exact pins are in [sources.json](sources.json). The laboratory observations are separate in [dossier.md](dossier.md). No third-party code was copied into the fixture.

[CPython msvcrt](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/PC/msvcrtmodule.c) forwards `_locking`, releases the GIL and converts failure to an OS error. Its [documentation](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/Doc/library/msvcrt.rst) defines current-offset ranges and nonblocking modes; LK_NBRLCK does not provide shared-reader locking. Reuse the existing runtime for an exclusive authority range, not as an invented reader-lock scheme. CPython's pinned license is PSF with included historical notices.

[Microsoft CRT documentation](https://github.com/MicrosoftDocs/cpp-docs/blob/63ae0763874ee0504e5f58ebdc32f99a67c5b560/docs/c-runtime-library/reference/locking.md) distinguishes access contention from bad descriptor/argument errors. Seek to the same offset before lock/unlock. The fixture retries only EACCES within 0.5 seconds and retains actual errors. It does not retry every OS error indefinitely.

[LockFileEx documentation](https://github.com/MicrosoftDocs/sdk-api/blob/f38eb1cccc6080c44fac242e8f6995abf983644d/sdk-api-src/content/fileapi/nf-fileapi-lockfileex.md) describes process-exit release and resource-dependent delay, with mapped-access limitations. Waited process exit alone is not proof of immediate lock reacquisition; test an actual bounded reacquisition. The exact UCRT-to-Win32 implementation path was not established by the CPython source, so do not claim the fixture directly called LockFileEx. [CreateFileW](https://github.com/MicrosoftDocs/sdk-api/blob/f38eb1cccc6080c44fac242e8f6995abf983644d/sdk-api-src/content/fileapi/nf-fileapi-createfilew.md) separates file sharing/open behavior from byte-range ownership. Use a precreated stable lock file; concurrent bootstrap and arbitrary replacement are outside the experiment. These Microsoft documentation repositories carry CC-BY-4.0 licenses at the recorded pins.

[Linux RCU explanation](https://github.com/torvalds/linux/blob/adc218676eef25575469234709c2d87185ca223a/Documentation/RCU/whatisRCU.rst) separates removal from reclamation after old readers finish, and separates update synchronization from reader protection. Adapt that conceptual distinction to durable named pins; do not import an RCU theorem into a Windows file fixture or treat elapsed time as a grace period. The pinned kernel COPYING describes GPL-2.0-only with its exceptions; this document has no independently established permissive code license. No kernel code is reused.
