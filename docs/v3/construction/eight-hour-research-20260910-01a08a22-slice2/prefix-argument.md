2026-09-10 — literal-prefix sharing argument and validation boundary

This is a conditional source argument, not an executed result or a general reduction theorem. The proposed experiment compares the 12 Packet 01 histories and 48 selected Packet 04 histories against fresh owned unreduced references. It does not reduce the 2,880 collection/publication race histories or exhaust the original 40,320-order scale profile.

Fix one original profile, unit and outcome. A tree node is one complete ordered tuple of literal action occurrences, including its original suffix indices. Assume the frozen initializers, transition functions and evidence constructors are deterministic for these inputs, and that ancestor state remains unchanged during descendant traversal. The empty-prefix node then has the same initial source and adapter states as an unreduced run.

For an inductive step, equal predecessor states receive the same original action at the same chronological depth. The unchanged source and adapter transition implementations and their auditors produce/check the same successors. The copied causal ledger receives the same before/after states, literal actions and chronological indices through r.advance. Thus the child states, ledger, response/journal comparison and trace events agree with the corresponding unreduced prefix. Full states feed transitions; partial adapter patches are evidence, not replacement states.

Sharing ends at prefix construction. Each leaf receives its original case ID and schedule-first filename, and unchanged audit_case regenerates all relations and case-specific identity proofs. Proofs bind the case, chronological prefix, event-prefix hashes and state hashes; they cannot be shared between cases. Original profile actions and Q completion positions remain unchanged. Typed encoding, ordered records, canonical JSON and deterministic gzip then supply an executable compressed-byte comparison against the independent reference certificate.

The implementation checks typed ancestor fingerprints after every child subtree and counts every independently initialized root and executed prefix before transitions. These checks test the induction premises in the declared finite runs; source review supports the claim that reference states do not drive exploration. The wrong-reference-leaf control tests mapping, not the absence of a malicious oracle-copy implementation.
