# Competitive note — T3 Code v0.0.45

Evidence class: **source-documented** (public release notes / README), retrieved and date-pinned
2026-10-02. Not downloaded, installed or executed. **No adoption, no decision** — this note changes
nothing.

## What it is

`pingdotgg/t3code` (public; ~24.3k stars / 6.3k forks at retrieval) describes itself as an "agent
harness control surface": control the agents on your machine from a mobile app (iOS, Android), a web
app and an Electron desktop app. It works with subscriptions on **Claude Code, Codex, Cursor, Grok
Build and OpenCode** — if they are set up on your computer, T3 Code can drive them. Its stated
positioning is "performant, remote-ready and truly open" (forkable).

## Implications for Recursion (inference; not adopted)

- **Mobile is the live frontier, and T3 Code bet on React Native/Expo**, not native Swift/Kotlin,
  with deep OS integration (Live Activities, Android widgets, per-thread notification stacking). This
  is a direct data point for the O-04 native-vs-RN question (**D-039**): the iOS/Android advisory's
  "RN is a genuine comparator" caveat is well-founded, and RN is demonstrably production-credible at
  scale.
- **"Restart the session to load new skills/plugins"** is a lifecycle pattern relevant to R-PC/R-UI
  contribution reload and the plugin architecture (D-019/D-035): plugins/skills are picked up by
  session restart rather than hot-reload.
- **Multi-subscription control surface** confirms the D-034 space: routing/driving other harnesses is
  table stakes. Recursion's claimed moat is deterministic composition plus authority, continuity,
  accounting and portability — not the router itself.
- **Upstream version tracking** (Codex 0.159) underscores D-023's need for maintained route
  descriptors and the `RouteCapabilityDescriptor` discipline.
- **Quota-by-credential** (OpenCode Go limits merged by credential) is relevant to R-D quota
  measurement and D-030 headless delegation/accounting.
- **Attention UX** ("busy threads until they need you") parallels the Attention/continuity lanes
  (R-UI, `INTERFACE-STRATEGY.md`).
