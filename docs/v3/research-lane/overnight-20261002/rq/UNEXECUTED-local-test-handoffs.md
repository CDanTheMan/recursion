# Unexecuted local acceptance handoffs

All eighteen fixtures are provider-free specifications. None ran. There is no verified memory implementation entrypoint, so no runnable command is supplied. Establish and pin the real entrypoint in a later explicitly admitted local session.

## Common prerequisites

- Explicit local owner admission for exact candidate/profile and synthetic-only workspace
- Reviewed implementation satisfying candidate-contracts.json, with fixed digest/version and capability settings
- Independent reviewer authors or checks oracle against synthetic-fixtures.json without reusing candidate reducer
- Network-deny/no-provider sink spies, filesystem inventory, process/job and durable-event instrumentation
- Baseline canonical journal plus current policy/tombstone and source manifests
- Declare scheduler/fault bounds, permitted observer nondeterminism and any time/resource limits before running
- No credentials, production files, accounts, remote hosts or provider clients

## Independent oracle

Hand-authored relation over exact canonical event sequence, source/rights labels, dependency graph, recipient binding and synthetic expected outputs; separate implementation/reviewer from candidate

## Evidence and stopping

- Exact candidate and dependency pins
- Input manifest digest and policy/profile revisions
- Canonical before/after journal and operation receipts
- Scope-redacted observer transcript and copy inventory
- Injected schedule and fault outcomes
- Expected versus actual comparison and intended-invariant mutant witness
- Instrumentation positive controls and zero-egress audit
- Independent acceptance or explicit blocked/unknown disposition
- Stop immediately on unapproved egress, credentials/real-data access, unexpected target effect or authority widening; preserve non-sensitive evidence
- A failed predicate yields FAIL; missing instrumentation/oracle/bound yields BLOCKED or UNKNOWN, never PASS
- After all declared cases and independent review, terminate the bounded fixture; do not keep a background worker
- Do not run these fixtures in the research session
