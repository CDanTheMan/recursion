# Unexecuted local media contract handoffs

Every fixture is UNEXECUTED. This document authorizes no execution. No verified product entrypoint was found; there are no runnable commands. Use the matching JSON for machine ingestion.

## Global Prerequisites

- Separate explicit authorization for local target execution
- Pinned implementation and independent oracle identities, shared contract revisions, exact OS/profile and synthetic input manifest
- No provider credentials or live endpoints; deny-all provider/network/model dispatch tripwires, including helpers
- Freeze fixture bounds, deadlines and resource/fidelity policy before running; unset bounds produce BLOCKED_NOT_RUN
- Independent verifier and externally observed side-effect/resource evidence, not only implementation self-reports

## Global Stop Conditions

- Any attempted provider call, actual credential access, private media use or unapproved network effect stops the run and records failure
- Stop on adopted resource/deadline breach, uncontrolled child or missing independent oracle
- End only after all positive and negative cases have a reconciled outcome or explicit unresolved/blocker record; do not mark unknown as pass

A stub fixture validates contract behavior only. Actual decoder containment, terminal behavior and physical scheduling require a separately admitted pinned implementation and independent instrumentation.
