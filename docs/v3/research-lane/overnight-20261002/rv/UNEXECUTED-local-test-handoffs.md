# R-V UNEXECUTED local test handoffs

Future explicitly authorized provider-free local session only. No provider/model call, credential/account access, live host, telemetry endpoint, installation, repository edit or target execution is authorized by this research artifact.

No verified general R-V executable entrypoint exists. Bind the named logical operations through a separately reviewed adapter at an exact candidate pin; no runnable command is invented.

## Shared prerequisites

- Owner-approved exact candidate commit/build, schema/predicate/canonicalizer versions, readonly synthetic input directory, isolated output directory and independent verifier; no protected-path edits.
- No provider credentials, account identifiers or real project payloads; candidate adapters use only fixture stubs. All model, network and effect dispatch capabilities unavailable except independently trapped positive-control stubs.
- Independent observer can inspect the complete declared entrypoint/process/dependency boundary; failed positive controls or unobserved paths make the run UNVERIFIED.
- Adopt finite event/reference/depth/query/queue/artifact bounds from candidate-contracts.json synthetic profile or an explicitly frozen alternative; production latency/resource thresholds are prerequisites, not guessed defaults.
- Freeze test authorship, oracle independence, positive/negative expected outcomes, fault schedule and stop/cleanup method before target execution; do not generate expected output with the candidate reducer.

## Shared evidence and stopping rules

- Exact input/expected-output manifest and hashes; target/source/config/dependency identity; environment profile; invocation admitted separately; all timestamps with clock identity.
- Independent raw witness observations, target typed output, expected/actual comparison at each boundary, resource/coverage data, refusal and gap reasons, intended-negative-control sensitivity.
- Explicit result PASS|FAIL|BLOCKED|UNVERIFIED|NOT_RUN per case; unknown numeric quantities null with reason; no runtime pass claimed by artifact generation.
- Any unexpected model/network/actuator/credential/install/live-host attempt: stop at its independent tripwire without reaching endpoint.
- Any authority/privacy/integrity floor breach or missing witness: preserve bounded sanitized evidence and mark FAIL/UNVERIFIED; no automatic repair that changes the oracle.
- Predeclared resource/deadline/output ceiling reached: cancel boundedly, preserve last verified cut, wait owned local test processes using approved handles, record cleanup unknown if not evidenced.

Pure semantic cases use a synthetic adapter. Runtime isolation/timing cases require named D028 native Windows/Linux profiles. WSL2-ext4 and WSL2 /mnt/c remain separate dev/test cases; abrupt VM reset requires a separate authorized disposable rig.

- At2 retries no threshold alert; at3 one rule alert; duplicate/cooldown suppress repeat but record suppression
- Unknown coverage yields availability diagnostic not healthy; clock discontinuity explicitly unknown
- No worker/model/research/adaptation/credential activation, authority/budget mutation or unapproved notification attempt
- Rule output distinguishes facts, inferred cause and unknowns; no vendor-intent narrative

**Required evidence:**
- Typed diagnostic, operands/rule version, suppression counters, before/after policy digests and complete activation witness

**Stop:**
- Stop on self-activation, scope expansion, alert storm or false healthy classification

**A pass does not prove:**
- Absence of incidents, complete anomaly coverage, root-cause truth or optimization value
